Skyward Flight is an original 3D flight game built with Three.js: fly a little propeller plane over a procedural island valley, thread six glowing rings in the Ring Run mission, watch your fuel and stall speed, then bring her home for a gentle landing on the runway. Free flight is always open — take off and explore the mountains, sea and clouds. Keyboard and mouse controls, a chase camera that never fights the pilot, a live HUD (altitude, speed, heading, fuel, throttle, score), combos for clean ring runs, and damage on hard impacts. Deterministic screenshot scenes (`?shot=start|play|chase|end&seed=N`) stage real gameplay with an autopilot.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. No build step, no network at runtime — every file the game loads lives under `game/`.
